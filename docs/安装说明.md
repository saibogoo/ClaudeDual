# ClaudexDual 安装说明

ClaudexDual 是一个用于管理 Claude Desktop 开发者模式和第三方模型代理配置的 macOS 工具。

## 安装

1. 打开 `ClaudexDual.dmg`
2. 将 `ClaudexDual.app` 拖到“应用程序”目录
3. 双击运行 `ClaudexDual`

## 如果 macOS 提示无法打开

如果系统提示“无法验证开发者”或阻止打开，可以执行下面的命令信任本应用：

```bash
sudo xattr -r -d com.apple.quarantine /Applications/ClaudexDual.app
```

然后再次打开 `ClaudexDual.app`。

如果你还没有把 App 拖到“应用程序”目录，而是在下载目录中运行，则使用：

```bash
sudo xattr -r -d com.apple.quarantine ~/Downloads/ClaudexDual.app
```

执行后可以右键点击 `ClaudexDual.app`，选择“打开”。

## 在线升级

ClaudexDual 会在启动后检查 GitHub Release。也可以打开“关于”页，在“在线升级”区域手动检查。

发现新版本后，点击“下载升级包”。ClaudexDual 会先核对安装包大小和 SHA-256 摘要，校验通过后自动打开 DMG。将其中的 `ClaudexDual.app` 拖入“应用程序”并选择覆盖，即可完成升级。

升级不会修改 `~/Library/Application Support/ClaudeDual-3p` 中的配置和数据。

## 首次使用

1. 打开 ClaudexDual
2. 在“状态”页点击“一键开启开发者模式”
3. 选择或编辑配置
4. 点击当前激活配置右侧的“启动”

ClaudexDual 会自动创建 `~/Library/Application Support/ClaudeDual-3p` 数据目录，并写入基础配置。
